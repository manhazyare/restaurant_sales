# restaurant_sales
# 🍔 Restaurant Sales Analytics Project

Welcome to the Restaurant Sales Analytics Project repository! 🚀

This project explores transactional restaurant sales data to uncover actionable business insights — covering sales trends, product performance, revenue patterns, and manager/city-level performance. Designed as a portfolio project, it highlights practical skills in data analytics and SQL-based reporting.

## 📖 Project Overview

This project analyzes a dataset of restaurant transactions spanning November 2022, containing records with the following fields:

| Column | Description |
|---|---|
| Order ID | Unique identifier for each order |
| Date | Transaction date |
| Product | Menu category sold (Burgers, Fries, Beverages, etc.) |
| Price | Unit price of the product (USD) |
| Quantity | Units sold |
| Purchase Type | Channel — In-store or Online |
| Payment Method | Credit Card or Gift Card |
| Manager | Store manager responsible for the location |
| City | City where the transaction occurred |

**Products covered:** Burgers, Chicken Sandwiches, Fries, Beverages, Sides & Other

**Cities covered:** London, Madrid, Lisbon, Berlin, Paris

## 📊 Analytics & Insights

The analysis delivers insights across the following areas:

- **Sales Trends** — Daily and weekly transaction volumes by city and product
- **Product Performance** — Best and worst performing menu categories
- **Revenue Analysis** — Total and average revenue by product, manager, and city
- **Channel Analysis** — In-store vs. Online purchase breakdown
- **Payment Behavior** — Credit Card vs. Gift Card usage patterns
- **Manager Performance** — Revenue and order volume attributed per manager
